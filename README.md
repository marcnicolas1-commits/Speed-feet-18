# SpeedFeet V3.0 — Première base

Cette version démarre la refonte V3 à partir de la V2.11, sans supprimer les données ni les fonctions existantes.

## Première étape intégrée
- nouvelle identité visuelle V3 ;
- accueil entièrement réorganisé ;
- mise en page responsive pour iPhone et iPad ;
- en-têtes non fixes afin de préserver la surface utile ;
- bouton Retour placé systématiquement en haut à gauche des pages secondaires ;
- actions de validation maintenues en bas de page ;
- correction des couleurs de l'écran Apprentissage ;
- conservation de l'historique et des clés de stockage V2 ;
- nouveau cache PWA V3.

## Base fonctionnelle conservée
Préparation, GPS, enregistrement, virements, empannages, historique, analyse, records, succès, apprentissage, paramètres, import/export et sauvegarde restent disponibles.
